# Kinski Pflege

Tägliches Dashboard für Pillen und Futter – offline-fähig, Daten nur auf dem Gerät.

## Nutzung

Öffne die Seite und optional **Zum Home-Bildschirm** hinzufügen (Tablet/Handy).

Dauerhafte Adresse nach GitHub Pages:

**https://eyecue-create.github.io/kinski-care/**

## Funktionen

- Morgens / Mittags / Abends nach Plan
- Abhaken mit Uhrzeit
- Futter-Notizen (Sorte, Appetit)
- Überfällig-Hinweis + optionale Browser-Erinnerung
- Kalium mittags nur bis inkl. 19.08.2026
